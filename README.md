# TaskFlow

سامانهٔ مدیریت سفارش، پروژه، گردش کار و وظایف تیمی بر پایهٔ تمپلیت مشترک PHP 8.2 / MariaDB.

## امکانات اصلی

- ساخت حساب برای کاربران و مدیریت نقش‌ها و دسترسی‌ها
- ادمین با دسترسی کامل و امکان تعریف ادمین/مدیر جدید
- گروه‌بندی کاربران در تیم‌ها و عضویت هر کاربر در چند تیم
- تعریف پروژه و اعضای پروژه
- مدیریت مشتری و اتصال چند مشتری به هر سفارش همراه با وزن
- تعریف اولویت‌های داینامیک برای سفارش
- قالب گردش کار داینامیک با مراحل، ترتیب، وزن پیشرفت و وابستگی چندگانه
- تخصیص پیش‌فرض هر مرحله به کاربر، تیم یا نقش
- ایجاد خودکار Task هنگام فعال‌شدن مراحل قابل اجرا
- تخصیص یک Task به چند نفر؛ تأیید یک نفر برای تکمیل کافی است
- فعال‌شدن خودکار مراحل بعدی پس از تکمیل همهٔ پیش‌نیازها
- محاسبهٔ درصد پیشرفت وزنی سفارش از صفر تا صد
- گزارش‌های چندگانه برای هر Task
- History تغییرناپذیر برای سفارش و Task
- اعلان داخل پنل برای تخصیص و فعال‌شدن وظایف
- افزودن، غیرفعال‌کردن و جابه‌جایی مراحل یک سفارش فعال بدون حذف History
- پیوست چند تصویر به سفارش
- فیلتر سفارش‌ها و وظایف بر اساس مشتری، وزن، نوع، وضعیت و اولویت
- رابط فارسی، RTL و ریسپانسیو بدون وابستگی به CDN

## نصب سریع

```bash
cp .env.example .env
php -r "echo bin2hex(random_bytes(32)), PHP_EOL;"
# APP_KEY و اطلاعات DB را در .env تنظیم کنید.

php bin/console migrate
php bin/console admin:create admin@example.com
php -S 127.0.0.1:8080 -t public public/router.php
```

سپس وارد `/login` شوید. فضای کاری اصلی در `/workspace` قرار دارد.

در Apache/DirectAdmin باید Document Root روی پوشهٔ `public/` باشد.

## منطق Workflow

با فعال‌شدن سفارش، مراحل قالب به‌صورت snapshot داخل سفارش کپی می‌شوند. مراحل بدون پیش‌نیاز فعال و Task آن‌ها ساخته می‌شود. با تکمیل یک Task، مرحله کامل می‌شود، پیش‌نیازها دوباره بررسی می‌شوند و مراحل آماده به‌صورت خودکار فعال خواهند شد. زمانی که تمام مراحل فعال سفارش کامل یا غیرفعال باشند، سفارش تکمیل می‌شود.

هر تغییر بعدی روی قالب فقط سفارش‌های آینده را تحت تأثیر قرار می‌دهد. Workflow یک سفارش فعال از طریق APIهای مخصوص همان سفارش و بدون حذف History قابل تغییر است.
